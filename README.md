# Justine BSL - interactive prototype

Static build of the working prototype (6 October 2026): a closed set of signs to practise
against a filmed reference, camera handshape practice, and the guide panel.

**Read this before showing it to anyone.**

- The camera tracks hand position and checks a handshape against a recorded reference.
  It does **not** understand or translate signing, and this page must never claim it does.
- No sign is ever generated or animated. Signing comes from real footage of a real signer.
- The guide is an AI, not Justine, and says so.
- The guide panel needs a server, so it is inert on this static copy: everything else works.
- The avatar is a cartoon derived from a photograph with consent; the photograph itself is
  not published anywhere.
